# 🔗 Open All Links - 智能浏览效率工具

一个现代化的 Chrome 浏览器扩展，通过智能链接分类和批量操作，大幅提升你的浏览效率。

## ✨ 核心功能

### 🧠 智能链接分类
- **AI驱动的内容识别**：智能区分内容链接、导航链接、侧边栏链接
- **网站特定优化**：内置GitHub、知乎、简书等热门网站的专用规则
- **多种过滤模式**：智能推荐、内容链接、所有链接、导航链接
- **自适应学习**：记住你的选择偏好，越用越智能

### 🎨 现代化界面设计
- **可折叠面板**：默认折叠状态，节省屏幕空间
- **美观的渐变设计**：现代化视觉效果，不再突兀
- **智能状态指示**：不同操作状态用颜色和动画区分
- **快速操作区**：一键开启选择、智能推荐打开

### ⚡ 高效交互体验
- **键盘快捷键**：全套快捷键支持，解放鼠标操作
- **面板控制**：可拖拽、固定、折叠的智能面板
- **批量操作**：一键打开推荐链接，支持数量限制
- **实时反馈**：操作状态实时显示，用户体验流畅

## 🚀 安装方法

### 方法一：开发者模式安装（推荐）

1. **下载源码**
   ```bash
   git clone https://github.com/your-username/open-all-links.git
   cd open-all-links
   ```

2. **生成图标文件**（如果需要）
   - PNG图标文件已经包含在项目中
   - 如需重新生成，运行: `npm run generate-icons`
   - 确保有 `icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`

3. **加载扩展**
   - 打开 Chrome 浏览器
   - 访问 `chrome://extensions/`
   - 开启右上角的"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目文件夹

4. **完成安装**
   - 扩展会出现在工具栏中
   - 点击图标即可开始使用

### 方法二：打包安装

1. 在扩展管理页面点击"打包扩展程序"
2. 选择项目文件夹生成 `.crx` 文件
3. 拖拽 `.crx` 文件到扩展管理页面安装

## 📖 使用指南

### 基本使用流程

1. **访问目标页面**
   - 打开包含多个链接的页面（如文章列表、搜索结果等）

2. **激活插件**
   - 点击浏览器工具栏中的插件图标
   - 或使用快捷键 `Ctrl+Shift+L` 直接开启选择模式

3. **快速智能操作**（推荐）
   - 点击面板上的"智能推荐"按钮，AI会自动识别并打开内容链接
   - 无需手动选择，一键完成批量浏览

4. **手动精确选择**（可选）
   - 点击"开启选择"按钮进入选择模式
   - 页面中的链接旁会出现复选框
   - 手动勾选需要的链接或使用"全选"按钮
   - 点击"打开选中"批量打开

5. **高级过滤选择**
   - 使用过滤下拉菜单选择不同类型的链接
   - 智能推荐：AI筛选的高质量内容链接
   - 内容链接：排除导航菜单的主要内容
   - 所有链接：页面中的全部链接
   - 导航链接：主要是菜单和导航类链接

### 高级功能

#### 智能分类系统
- **网站特定优化**：内置GitHub、知乎、简书、Stack Overflow等热门网站规则
- **AI驱动识别**：自动区分内容链接、导航链接、侧边栏链接
- **自适应学习**：记住用户选择偏好，使用越多越精准

#### 键盘快捷键
- `Ctrl+Shift+L`：开启/关闭链接选择模式
- `Ctrl+Shift+A`：全选当前显示的链接
- `Ctrl+Shift+O`：打开所有选中的链接
- `Ctrl+Shift+Q`：快速打开智能推荐链接
- `Ctrl+Shift+C`：折叠/展开控制面板
- `Escape`：关闭面板（未固定时）

#### 面板控制
- **可折叠界面**：节省屏幕空间，默认折叠状态
- **拖拽定位**：鼠标拖拽面板标题栏可移动位置
- **固定功能**：防止误操作关闭，保持面板稳定
- **状态记忆**：记住面板位置和折叠状态

#### 设置选项
- **新窗口打开**：选择在新窗口或新标签页中打开链接
- **标签页限制**：防止同时打开过多标签页导致浏览器卡顿
- **最大数量**：设置同时打开的标签页上限（5-50个）
- **过滤模式记忆**：记住用户偏好的过滤设置

## ⚙️ 配置说明

### 权限说明
插件需要以下权限：
- `tabs`：创建和管理标签页
- `storage`：保存用户设置
- `activeTab`：访问当前活动标签页的内容

### 默认设置
```json
{
  "openInNewWindow": false,    // 在新标签页中打开（默认）
  "limitTabs": true,           // 启用标签页数量限制
  "maxTabs": 20               // 最大标签页数量
}
```

### 自定义设置
用户可以通过弹窗界面调整以下设置：
- 链接打开方式（新标签页/新窗口）
- 是否限制标签页数量
- 最大标签页数量（5-50个）

## 🐛 故障排除

### 常见问题

**Q: 控制面板没有显示怎么办？**
A: 首先点击插件图标检查页面兼容性。某些特殊页面（如chrome://）不支持插件。可以尝试刷新页面或切换到普通网站。

**Q: 智能推荐功能不准确？**
A: 智能推荐会根据网站特性自动调整。如果效果不理想，可以切换到"内容链接"模式手动选择，系统会学习你的偏好。

**Q: 如何快速使用而不显示面板？**
A: 使用快捷键 `Ctrl+Shift+Q` 可以直接打开智能推荐的链接，无需显示控制面板。

**Q: 面板太占空间怎么办？**
A: 面板默认是折叠状态。你可以：1) 点击折叠按钮收起面板 2) 使用快捷键操作 3) 点击固定按钮后按Escape键隐藏。

**Q: 打开的链接数量比选择的少？**
A: 检查设置中的"最大标签页数量"限制。为保护浏览器性能，系统会自动限制同时打开的标签页数量。

**Q: 如何调整控制面板的位置？**
A: 控制面板的标题栏（渐变色区域）是可拖拽的，点击并拖拽即可移动到页面任意位置。
