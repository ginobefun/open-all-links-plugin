页面显示规则

配置插件在哪些页面显示或隐藏控制面板：

  • 不限制：在所有页面生效
  • 黑名单：在匹配的页面上不显示
  • 白名单：仅在匹配的页面上显示

URL 规则支持 * 通配符，例如：

  • *.github.com/* 匹配所有 GitHub 页面
  • example.com/blog/* 匹配特定路径
